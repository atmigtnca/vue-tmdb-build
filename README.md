# vue-tmdb-build

초급프로젝트 실습 2) Vue의 배포 — (1) Vue → H/C/J (build) → GitHub Pages 방식.

Vue 프로젝트를 `npm run build`로 빌드한 결과물(`index.html`, `assets/`의 CSS·JS)만 올리고, GitHub Pages가 main 브랜치를 그대로 정적 배포한다.

- 사이트: https://atmigtnca.github.io/vue-tmdb-build/
- 원본 Vue 프로젝트: https://github.com/atmigtnca/vue-tmdb-actions
